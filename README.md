# 🔍 SCOPUS Article Search Application

Application Java pour rechercher des articles scientifiques par nom d'auteur dans la bibliothèque SCOPUS.

## 📋 Fonctionnalités

- ✅ Recherche d'articles par nom d'auteur
- ✅ Affichage détaillé des résultats
- ✅ Informations complètes (titre, auteurs, journal, citations, DOI)
- ✅ Interface console simple et intuitive

## 🛠️ Technologies Utilisées

- Java 11
- Maven
- Apache HttpClient
- Gson (parsing JSON)
- SCOPUS API

## 🚀 État du Projet

🔄 **En cours de développement**

## ▶️ Lancement

Avant de lancer l'application, configurez votre clé API SCOPUS dans une variable d'environnement:

```bash
export SCOPUS_API_KEY="votre_cle_api"
mvn package
java -jar target/scopus-search-app-1.0-SNAPSHOT.jar
```
